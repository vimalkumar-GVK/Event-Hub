So, what exactly is the real-world problem here? Right now, if a department hosts a hackathon or a cultural fest, they usually just send out a Google Form link on WhatsApp. Students register there, but then there's no central place for organizers to track those registrations. On the day of the event, attendance is usually taken on paper. This means long queues, and people can easily fake it or do proxy check-ins for their friends. And worst of all, after the event, organizers have to manually type out names, create certificates one by one, and email them, which can take weeks. [Pause]

We want to bring students, organizers, and college administrators under one unified, secure roof. We’re replacing paper attendance with instant, foolproof QR code check-ins, and we’re completely automating the certificate distribution process so students get verifiable PDFs immediately after the event ends.

[1:45 - 3:15] Tech Stack & Architecture
[Show Slide 5]
Now, let's talk about the engineering behind this. For the tech stack, I carefully selected tools that provide high performance, scalability, and a great developer experience. 

On the frontend, I used React 19 and TypeScript. I chose Vite as the build tool for lightning-fast hot module replacement, and styled the entire application using Tailwind CSS to achieve a modern, minimal, and responsive look without writing thousands of lines of custom CSS. 

For the backend, I used Python with Flask. I intentionally paired this with a MongoDB database. Since events can have wildly different structures—some are team events, some are solo, some have multiple sub-competitions—MongoDB's flexible document-based structure was perfect for handling this dynamic data. 

I also wanted the platform to feel alive, so I implemented WebSockets using Flask-Sock to create a real-time chat feature between students and organizers. Finally, the whole system is secured using JWT authentication. [Pause]

[Show Slide 6]
Let’s look at the system architecture. [Point to diagram flow] 
Here’s how data flows through our ecosystem. It starts when a college Administrator approves an event proposed by a student Organizer. Once approved, the event instantly goes live on the student Web App. 

A student registers, and the React frontend sends that data to our Flask REST APIs, safely storing the registration in MongoDB. The system then generates a unique QR code ticket and assigns it to the student. When the organizer scans that ticket at the venue, the API updates the database in real-time, marking them present. Finally, the backend Python script utilizes ReportLab to generate a PDF certificate and pushes it straight to the student's dashboard.
