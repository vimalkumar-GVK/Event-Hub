## 🐛 **Bug #5: Login Popup Not Centered**
### **Issue:**
The login/signup cards were aligned to the left side of the screen instead of being centered.
### **Fix:**
Updated `js/app.js`:
- Applied explicit inline flexbox styles (`display: flex`, `align-items: center`, `justify-content: center`) and `width: 100%` to the parent wrapper in `renderLogin` and `renderForm`.
- This ensures the login card is perfectly centered regardless of external CSS conflicts.


---

## 🐛 **Bug #6: SQLite Time Type Error**
### **Issue:**
When saving an event draft, the backend crashed with `SQLite Time type only accepts Python time objects as input`.
This occurred because the frontend sends time strings (e.g., "10:00") which SQLAlchemy/SQLite rejected.
### **Fix:**
Updated `backend/main.py`:
- Added `parse_date` and `parse_time` helpers.
- Sanitized `date`, `time`, `start_time`, and `end_time` in `create_event` and `update_event` routes.

---

## 🐛 **Bug #7: Create Event / Save Draft "Not Working" (Frontend Validation)**
### **Issue:**
User reported "Create button is not working". This was likely due to strict validation requiring at least one sub-event, which was failing silently or with a missed toast notification if the user didn't add a session.
Additionally, if the user session was invalid, the save action might fail silently.
### **Fix:**
Updated `js/app.js`:
- Added explicit `alert()` for missing sub-events validation in `handleEventSubmit`.
- Added explicit user session check in `handleSaveDraft` with `showToast` feedback.
- Backend restart confirmed to apply fixes.
